# 四字熟語あつめ（試作）

漢字の部品をみんなで持ち寄って、四字熟語を完成させるゲーム。読みと意味をヒントに、机の4つの枠に部品をはめる。

- 机はボードと場をかねる。正しい枠に置けばはまる。枠の外やまちがった枠に置いた部品は机に転がり、だれでも拾える
- 点は1文字ごと：速さ（その文字ができるまでの時間）と協力（何人で作ったか・ほかの人に配られた部品を使ったか）。四字熟語ができたらボーナス
- いまは、ひとり＋CPU の仲間（0〜3人）で遊べる。みんなで遊ぶ部屋は、このあと

## ファイル

- `index.html` … ゲーム
- `data.js` … 四字熟語の一覧と、漢字の部品の形（`node tools/build-data.js` で作る。手で書きかえない）
- `tools/build-data.js` … 四字熟語の一覧（ここに書く）と、KanjiVG から部品を切り出す処理
